# Daily Log

A running log of each day I commit a solution. One row per day keeps the
[GitHub contribution graph](https://docs.github.com/en/account-and-profile/setting-up-and-managing-your-github-profile/managing-contribution-graphs-on-your-profile/why-are-my-contributions-not-showing-up-on-my-profile) green — GitHub counts any commit made to this repo's
default branch on the account's contribution graph, as long as the repo is public
(or you've enabled private contributions in your profile settings).

| 1 | 2026-07-19 | [Two Sum](https://leetcode.com/problems/two-sum/) | [Arrays](./01-Arrays) | C++, Java, Python | Warm-up, hash map approach |

> Add a new row every time you commit a solution. `scripts/daily.sh` does this
> automatically (see root README → "Daily Contribution Workflow").
